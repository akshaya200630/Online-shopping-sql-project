# Online Shopping Sales Analysis Using SQL

## Project Introduction

This project demonstrates an Online Shopping Sales Analysis database built using MySQL. It contains a realistic e-commerce dataset with four related tables: **Customers, Products, Orders, and Order_Items**.

The project is designed to practice SQL from beginner to intermediate level by performing data retrieval, filtering, sorting, aggregation, joins, and subqueries on a relational database.

---

## Project Objectives

- Analyze customer information and purchasing behavior.
- Analyze products based on category, brand, price, stock, and rating.
- Track customer orders and order status.
- Calculate total sales and revenue using SQL queries.
- Identify high-value customers.
- Find best-selling products.
- Practice SQL joins between multiple tables.
- Use subqueries to solve analytical problems.
- Apply aggregate functions such as `COUNT()`, `SUM()`, `AVG()`, `MIN()`, and `MAX()`.

---

## Database Structure

The project contains four tables:

| Table | Description |
|-------|-------------|
| Customers | Stores customer information |
| Products | Stores product details |
| Orders | Stores order information and status |
| Order_Items | Stores products included in each order |
